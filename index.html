Interactive Decision Webpage

Explore decision-making under uncertainty. Edit alternatives, states of nature, payoffs and probabilities, then compare decision criteria and staged filtering.

1. Decision model

Edit the names and payoff values directly in the table. Payoffs are assumed to be monetary outcomes; higher values are better.

State probabilities

Enter probabilities between 0 and 1. Their total must equal 1.00 for EMV/Bayes calculations.

2. Decision criteria results

All results update automatically when you edit the model. Ties are reported rather than arbitrarily broken.

Regret table · opportunity loss

3. Staged filtering

Choose a criterion for each stage. At every stage, the best remaining alternative(s) survive; ties are retained. The next stage evaluates only those survivors.

4. How the criteria work

Maximax (optimistic)

For each alternative, find its highest payoff. Choose the alternative with the highest of these values.

Maximin (pessimistic)

For each alternative, find its lowest payoff. Choose the alternative with the highest of these minimum values.

Minimax Regret

For each state, subtract each payoff from the best payoff in that state. Choose the alternative with the smallest maximum regret.

EMV / Bayes

Multiply each payoff by its state's probability and add the products. Choose the alternative with the highest expected monetary value.
